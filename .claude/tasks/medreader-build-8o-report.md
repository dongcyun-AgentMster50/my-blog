# 8o Build 보고 — 빈칸 낭독 (F5a) (2026-10-21)

설계: spec 19-1-3 §6 "8o" + 결정 L-D11 (가) · L-D8 (나). **8o-2(보기 `(A)` 인식)는 건드리지 않았다.** **커밋하지 않았다.**
전체 테스트 **1338/1338**(1322 + 새 16) × 2회, stamp `--check` 0, 변이 7개 모두 빨강 → 복원(cmp 같음), headless Edge — 아래 6.

## 1. 규칙 (`js/tts/text.js` — 낭독 사본에서만)
- **꼴**(spec 그대로, 조사에서 센 것만): `-{4,}` · `_{3,}` · `–{3,}` · `—{2,}`. 걸리지 않는 것: `---`(3개) · `--` · `—` 하나 · `––` · `__` · 범위 `10-20`·`3–4` · 낱말 속 하이픈 · 줄 끝 하이픈 결합(`cardio-`) · 목차 점선 · 띄어 쓴 `- - - -`.
- **구분선·괘선 제외**: 줄 **전체**가 꼴 글자·`= + |`·공백뿐인 줄(`----------`, `|------|-----|`, `+-----+`, `______  ______`)의 꼴은 그대로. 판정은 문장 조각이 아니라 **문단 좌표의 줄 전체**(`ruleZones` — 문장 모드는 `joined.base` 에서 줄을 보고 `from` 만큼 당긴다). URL·이메일 안의 꼴도 그대로(→ "link").
- 꼴이 글자에 붙어 있어도(`<-------`, `(______)`) 앞뒤를 띄어 낱말로 바꾸고 공백·구두점 앞 공백을 정리한다. 꼴이 없거나 하나도 안 바꿨으면 입력 그대로(8o 이전과 바이트 같음).
- 꼴 앞에서 문장을 새로 나누지 않는다(분할 규칙·`seg`·`ranges` 무변). 줄 끝 빈칸은 하이픈 결합이 아니다(`hyphen.js` 가 `--` 로 끝나면 공백으로 잇는다 — 테스트로 고정).
- 자리: `normalizeSpeech(text, symbols, {blank, keep})` 의 **첫 단계**(원문 좌표가 살아 있을 때 — `speechMarks` 앞). `emit` 이 `blank`(낱말)·`keep`(구분선 구간)을 넘긴다. `src`·`ranges`·입력 줄은 손대지 않는다.

## 2. 언어별 낱말 (`js/config.js` `SPEECH_BLANK`)
`{ en:'blank', ko:'빈칸', fr:'blanc', ar:'فراغ' }` — 언어 = **`Unit.lang`(8m) ‖ 문서 언어**(`buildUnits` 의 meta 에 `lang` 을 더함). 언어 없음 → en(기호 표와 같은 규칙), **표에 없는 언어 → 쉼표 하나**(`und`·`es` 등). **ar 은 spec 에 문안이 없어 Build 가 골랐다**(8m 이 아랍 문자 단위에 `lang:'ar'` 을 주므로 필요) — fr·ar `[검토 — Nour·운영자]`. es 는 8n 몫(넣지 않음).
- 8m 의 알려진 한계가 그대로 이어진다: en 문서에서 "영어 문장. 한국어 문장." 이 한 단위(섞임 → 문서 목소리 → 문서 언어 낱말).

## 4. 불변 확인
- **화면 글자**: `buildUnits` 입력 줄 불변(T-B4), `ranges` 가 가리키는 화면 글자는 꼴 그대로. headless 에서 화면의 꼴 수 재생 전후 같음.
- **번역 요청·캐시 키**: `src` 불변(실물 0건 바뀜), readalong 요청 글자에 꼴 그대로·낱말 없음(T-B4), `keyFor` 같음. headless 요청 항목도 꼴 그대로.
- **검색**: 검색은 저장 글자를 쓰고 `tts/text.js` 를 거치지 않는다 — `speechBlanks`·`SPEECH_BLANK`·`blankWordFor` 를 쓰는 곳은 `tts/text.js`·`config.js` 뿐(grep 테스트).
- **단일 언어 의학책 큐**: 의학책 꼴 픽스처(범위·`--`·`—`·줄 끝 결합·`---`·`––`·`__`·구분선·괘선·URL 밑줄)와 합성 2단 쪽 — HEAD `tts/text.js` 로 만든 sha256 지문과 같음(언어 3 × 문장·줄 × 전환 켬/끔 = 24). 실물은 위 3.
- DB 버전·`algoVersion`·캐시 키·`SEARCH`/`SCAN` 버전·`PROMPT_VERSION` 불변.
