# 15-2d — 숫자 표현 덩어리 한 규칙 (15-2cR #1–#4, 오케스트레이터 결정)

같은 범위·규칙이다(`grounding.js` · `grounding-15` 시험 · spec 정정 줄 · stamp). 커밋 0 · 진짜 키·요청 0 · 서버 0 · 백그라운드 0. CMDT PDF 는 하네스가 적힌 경로로 읽기만 했다(Downloads 목록 0 · 원서 글 출력 0).

## 규칙 (`numberSpans` · `inNumber`)
- **덩어리**는 수(`\p{Nd}` + 붙은 위첨자 숫자 `SUP`)들이 이음 기호로 이어진 것이다.
  - `.`·`,`·`٫`·`٬` 는 **붙어서만** 잇는다.
  - `:`·`/`·`^`·`×`·`x`·`-`·`–`·`—`·`−`(`NUM_JOIN`)는 양옆 공백 **한 칸까지** 허용한다.
- 덩어리 앞에 부호·비교 기호(`SIGN`)를 붙인다. 공백 한 칸까지 허용하고, 그 기호 바로 앞이 글자면 붙이지 않는다.
- 덩어리 뒤에 `%`·`‰`·`°`·`٪`(`UNIT`)를 붙인다. 공백 한 칸까지 허용한다.
- 인용의 시작·끝이 **덩어리 안**(처음·끝이 아닌 곳)이면 `mid-word` 다. 시작·끝 대칭이다.
- 단위 낱말(`mg`·`L`·`C`)은 덩어리에 넣지 않는다. 서식 글자(`\p{Cf}`)는 건너뛴다. 마지막 문단 하나를 기억한다(`spanMemo`).
- 대신한 것: `signBefore`·`NUM_LINK`·끝 쪽 `UNIT` 줄·`joins` 의 수 쪽 갈래. `joins` 에는 글자·숫자 사이 하이픈·`:`·`/`(`pain-free`·`mg/kg`·`COVID-19`)만 남았다.
- **더 너그러워지는 꼴 0**(논리): 옛 판정은 모두 덩어리 판정 안에 든다. 옛 판정 → 덩어리 판정의 대응은 아래와 같다.
  - 수 사이 붙은 `.`·`,`·대시·`^` → 덩어리의 붙은 이음이다.
  - `signBefore`(공백 한 칸 · 기호 앞 글자 아님) → 덩어리의 앞쪽 부호와 같은 조건이다.
  - 끝 쪽 단위 → 덩어리의 뒤쪽 단위다.
  - 글자 사이 이음 → `joins` 그대로다.
  - 아래 하네스에서도 "폐기 기대"가 통과로 간 것은 0이다.
- **결정과 다른 점 하나**: `.`·`,`·`٫`·`٬` 는 공백을 허용하지 않는다.
  - 까닭: 띄운 꼴은 소수·천 단위가 아니라 문장 끝·나열이다(`…was 5. 10 patients…`·`doses of 5, 10 and 20`). 허용하면 문장이 수로 시작하는 정당 인용이 폐기된다.
