## 0. 한눈에

- **PDF 323개 중 322개가 영어 폴더**, 중국어 1개(25쪽), **일본어·스페인어 PDF 0개.** 일본어·중국어 자료는 mp3·hwp·doc·zip 이 대부분이다. 일본어 PDF 는 **zip 4개 안에만** 있다(이름으로 확인 — 지침대로 열지 않았다).
- 영어 PDF 23,683쪽 중 **스캔본 46개(8,089쪽)**, 글자 없음 1개(341쪽), **글자가 깨진 텍스트 PDF 60개(384쪽)** → 앱에서 낭독·번역이 안 되는 PDF 가 **107개, 8,814쪽(쪽 기준 37%)**. 이미 OCR 층이 있는 PDF 10개(2,519쪽).

- 앱의 빈칸(합성 문장으로 확인): **스페인어를 프랑스어로 추정**한다(score 1), 중국어·일본어는 `。？！` 에서 **문장이 안 나뉘고**, 줄 잇기가 한자 사이에 **공백을 넣고**, 검색은 **한자 안의 낱말·조사 붙은 한국어 2–3자 낱말을 못 찾고**, 토큰 추정은 중국어를 **약 3–4배 적게** 잡는다.

## B. PDF 진단 (323개 전수 — 표본으로 줄이지 않음)

방법: 파일마다 별도 node 프로세스, **상한 60초**(실제 평균 0.51초, 최대 2.5초, 전체 356초). 암호·손상으로 열리지 않은 파일 **0개**. O1 규칙은 spec 17-5-1 2 의 `probePages`·`scanVerdict` 를 그대로 옮겼다(10–90% 구간 12쪽, 75% 이상 글자 0 → 최대 2쪽 이미지 확인 → scan/notext). "OCR 층"은 글자 있는 표본 2쪽 모두 이미지 + 보이지 않는 글자(Tr 3)인 것. "깨짐"은 표본 글자 중 FFFD·PUA·제어 문자 > 1% 등(아래).

## E. OCR 대상 (스캔본·글자 없음·깨짐 — 영어 폴더만)

전체 목록: 스크래치패드 `survey/ocr-targets.tsv`(우선 A/B · 방식 · 언어 · 쪽 · MB · 사본 · 경로). 제외: `position edu` 4개(어학 자료 아님), `test-OCR.pdf`(운영자 시험본), `Cambridge.Advanced.Grammar.in.Use.[2nd.edition.2005].pdf` 2개(이미 `…[OCR].pdf` 있음).

| 묶음 | 파일 | 쪽 | 크기 | 방식 | 언어 데이터 |
|---|---|---|---|---|---|
| 스캔본 — Grammar in Use·Longman·발음·회화(우선 A) | 22 | 3,788 | 782 MB | `--skip-text` | `eng` |
| 스캔본 — 한국 출판 추정(문단열 EnglishCafePlus · 영어속독 Restless 6 · SQR3 Exploring English) (B) | 8 | 657 | 약 62 MB | `--skip-text` | `eng+kor` `[가정 — 한국어 해설 여부 미확인]` |
| 글자 없음 — Harry Potter Chamber of Secrets (B) | 1 | 341 | 1.1 MB | `--skip-text`(글자 층이 없어 그대로 OCR 됨) | `eng` |
| **깨진 글자 층 — 스피쿠스 unit 1–60** (B) | 60 | 384 | 41 MB | **`--force-ocr`**(`--skip-text` 면 글자가 "있는" 쪽이라 건너뛴다) | `eng+kor` |
| 사본(같은 쪽 수·같은 바이트) — 하지 않음 | 9 | 2,209 | | | |

- 중복 제외 합계 **스캔·글자 없음 31개 4,786쪽(846 MB) + 깨짐 60개 384쪽**. 크기만 조금 다른 같은 책(예: Essential Grammar in Use 299쪽 73.3 MB 두 벌)이 남아 있어 실제 권수는 더 적다.
- 이 PC 의 Tesseract 5.4 에는 `eng`·`osd` 만 있다(spec 17-5-1 실측) — B 묶음과 스피쿠스는 `kor.traineddata` 설치가 먼저다. `chi_sim`·`jpn`·`spa` 는 대상이 없어 필요 없다.
- 시간 `[추정]`: 쪽당 약 2초(17-5-1 실측, 150 dpi → `--oversample 300`) × 5,170쪽 ≈ 3시간(코어 수에 따라 줄어듦).

명령 초안(**실행하지 않았다** — 운영자 PC, PowerShell, 결과는 원본 옆 `…[OCR].pdf`):

```powershell
# ocr-targets.tsv(스크래치패드 survey/)를 운영자 PC 로 복사해 쓴다. 사본 열이 빈 줄만.
$rows = Import-Csv -Delimiter "`t" -Path .\ocr-targets.tsv -Encoding UTF8 | Where-Object { $_.'사본' -eq '' }
foreach ($r in $rows) {
  $src = $r.'경로'
  $dst = [IO.Path]::Combine([IO.Path]::GetDirectoryName($src), [IO.Path]::GetFileNameWithoutExtension($src) + '.[OCR].pdf')
  if (Test-Path -LiteralPath $dst) { continue }
  $mode = if ($r.'방식' -eq 'force-ocr') { '--force-ocr' } else { '--skip-text' }
  py -m ocrmypdf -l $r.'언어' $mode --rotate-pages --deskew --oversample 300 --output-type pdf $src $dst
}
```
- `--force-ocr` 와 `--deskew` 는 함께 쓸 수 있다(쪽을 다시 그린다 — 화질이 바뀔 수 있음). `--skip-text` 는 Tagged PDF 거절을 피한다(17-5-1).
- 확인: `node apps/medreader/dev/measure-scan-o1.mjs "<…[OCR].pdf>" --ops none --layout` 또는 스크래치패드 `survey/diag-one.mjs`(상태가 `text(OCR 층)` 이고 깨짐 0 이면 됨).
