## 배경 (오케스트레이터가 확인한 것)
운영자가 2026-10-26 Nour 의 메시지 묶음을 붙여 넣었다. 내용은 Nour 가 **다른 AI 도구(Artifacts)로 자기 시제품 앱을 만들며 보낸 요청문**의 한국어 번역이다(각 요청 끝에 "ARTIFACTS"). 앱 이름·화면이 MedReader 와 다르다. 구성:
- **앞부분 큰 묶음** = 2026-10-18 에 받은 요청과 **같은 글**(spec 19-1-1 의 N1–N14 로 이미 분류·배치됨). 다시 분류하지 말고 "같음" 만 확인해 한 줄로 적어라(다른 곳이 있으면 그것만).
- **새로 온 것(10-26 오후 7:28·7:30)** — 시제품에 대한 말이지만 Nour 의 필요를 보여 준다. 아래 R1–R6 으로 분류한다:
  - R1 섹션 제목으로 찾기: 예로 "호흡기내과"(원문은 아랍어 — Nour 는 아랍어로 진료과 이름을 쳤을 가능성이 높다)를 치면 그 섹션 시작으로 가고 싶다. 지금은 찾지 못한다(시제품).
  - R2 언어 학습기의 마이크 버튼이 음성 명령에 반응하지 않는다(시제품 — N11 별도 앱 후보).
  - R3 세 언어 각각 원어민처럼 자연스러운 낭독 목소리.
  - R4 원본 쪽에서 지금 읽는 줄을 하이라이트.
  - R5 문장·낱말 글꼴이 겹쳐 보인다.
  - R6 (7:30) 쪽이 어떻게 나뉘었는지(단 구성) 분석해 읽는 순서를 바로잡아 달라 — "세로 방향(줄글)으로 쓰여 있다" = 단(段) 우선으로 위에서 아래.

## 할 일
1. R1–R6 각각: **MedReader 에서 지금 어떤가**를 코드·spec 근거로(파일:행), 분류(됨 / 진행 중 / 넣음 / 조건부 / 넣지 않음 — 19-1-1 과 같은 말), 어디로(기존 단계 또는 새 단계), 이유. "됨" 이면 Nour 에게 줄 **안내 한 줄**(화면 단추 이름 — 아랍어 UI 문구를 i18n/ar.js 에서 그대로).
2. **R1 깊게** — 지금 8g(검색·목차 탭·17-8-9 (가) 아랍어 안내)로 아랍어 진료과 이름을 쳤을 때 무슨 일이 나는지. 선택지를 비교하라(호출 0 우선):
   - (가) 지금대로(안내만) · (나) 17-8-9 (나) 단어장 대응(8f 뒤) · (다) **내장 "진료과·장 이름" 다국어 사전**(ar·ko·fr → en, 일반 의학 어휘 — 책별 튜닝 금지, 메모리 규칙) · (라) 17-8-9 (라) AI 버튼 · 그 밖에 네가 찾은 것.
   - (다)를 따질 때 **측정**: 의학책 3권의 PDF 개요(목차) 최상위·둘째 단계 제목을 뽑아, 일반 진료과·장기계 이름 사전(네가 초안 — 40~80개 표제어)이 몇 %를 덮는지. 사전 초안은 보고서에만(아랍어·프랑스어 표기는 `[검토 — Nour·운영자]`).
   - 결과 화면 자리(목차 탭에서 그 장으로 이동 등), DB·algoVersion·검색 버전 영향, 예상 시간.
3. **R3** — Android Chrome 은 음성 이름을 무시하고 `lang` 태그만 쓴다(8k 실측, `.claude/tasks/medreader-8k-carryover.md`). 그러면 "자연스러움"은 기기 TTS 엔진·음성 데이터가 정한다. (가) Nour 에게 기기 설정 안내(Google 음성 엔진의 언어별 고음질 음성 데이터 설치 등 — 확인 안 된 메뉴 이름은 `[확인 필요]`) · (나) 클라우드 신경망 TTS(키·비용·오프라인·개인정보 13절과 부딪침) — 비교하고 권장.
4. **R4·R6** — 원본 뷰 하이라이트(`.hl-line`, spec 888행 근처)와 단 우선 읽기 순서(588행 근처, P6)가 지금 코드에 있는지 확인. 있으면 "됨 + 안내", 의심 가는 실물(예: 3단·표·그림 많은 쪽)이 있으면 조건부로 측정 계획만.
5. **R5** — MedReader 에서 겹침이 생길 수 있는 곳(원본 뷰 캔버스 + 하이라이트 오버레이 어긋남, 리플로우 글꼴, 8d 블록)과 시제품 문제일 가능성을 나눠 적고, Nour 에게 받을 것(MedReader 화면 스크린숏인지)을 점검표 항목으로.
6. 배치: 지금 로드맵(`.claude/tasks/medreader-handoff.md` "2026-10-21" 절 — 8d 는 배포됨 `c6a2d5d`, 다음 8e → 9a → 9b → 8n → 8g-6 → 8c+8f → 18 …) 안 어디에 넣을지, 결정이 필요한 것은 **N-D1… 결정 표**(선택지·권장·이유)로. 19-1 기준 (1) "Nour 의 직접 요청 우선" 을 따르되 작은 것은 묶음으로.
7. Nour 에게 보낼 **짧은 답장 초안**(한국어 + 아랍어 — 아랍어는 `[검토 — 운영자]`): MedReader 에 이미 있는 것과 쓰는 법, 시제품의 마이크·언어 학습기는 MedReader 범위가 아님(별도 앱 후보), 받고 싶은 것(MedReader 화면의 겹침 스크린숏 등). 이 초안은 보고서에만.
