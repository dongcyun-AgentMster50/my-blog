## 3. 뼈대 요약

- **15 복습 묶음** — 범위 = PDF 쪽 `[a,b]`(장은 개요로 고름). 화면 `#/review/:docId/:range`: 진도(읽은 쪽) · 저장 요약·개요·개념도 · 📕 원서 섹션(쪽 겹침, 기존 퀴즈로) · 🤖 AI 문제(sectionId `ai-p{a}-{b}`, 섞지 않음) · 기억 카드(범위) · 필기. AI 출제는 10-4 그대로 + 언어는 값(대상+원문) + 숫자 거름, 입력 = **읽은 쪽 문단(저장 요약 문단 먼저, 쓴 문단 빼기, 6,000자)**, 누를 때 1호출·5문항, `QUIZ_JOB`(runJob 위), `byKind.quiz`. 퀴즈 화면에 🤖 배지·근거 블록·대상 언어 해설.
- **16 그림 개념도** — 입력 = 저장한 개요 글(경로 꼬리표)만. 1호출: 노드 ≤ 12(개요 경로 `p` 필수)·엣지 ≤ 16·관계 고정 8개('치료' 없음). 검증(경로·enum·숫자 거름, 엣지 < 2 면 실패). 배치 순수 `text/diagram.js`: 고리 끊기 → 가장 긴 경로 층 → 경유점 → 무게중심 4번 → 낱말 줄바꿈(측정 주입) → 행 폭 넘치면 접기 → RTL 거울. - **19 사례 이미지** — `ext/openi.js`(fetch, `credentials:'omit'`·리퍼러 없음·10초·content-type 검사) + 순수 `text/openi.js`(호스트 허용 목록·캡션 태그 제거·조건 표). 선택 줄 `[⋯]`→`[사례 이미지]`, 검색어 고칠 수 있음, 종류 칩, 2열 격자, 크게·캡션·조건·원 논문 새 탭. 고정 고지 두 줄. 저장·AI 전송·캡션 번역 없음. 막히면 `[Open-i 에서 열기]` 새 탭(18 추천 링크에도).
