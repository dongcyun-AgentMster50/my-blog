# Plan 지침 — 9b 음성 명령 (Nour 필수 — 핸즈프리 2)

> 너는 **Plan 서브에이전트**다. 구현하지 않는다. 앱 코드·테스트를 고치지 않는다. **커밋하지 않는다.** 한국어로 쓴다. 결과는 spec `apps/medreader/spec.md` 17-1 안 17-1-1 다음에 새 소절 **"17-1-2. 9b Build 설계 — 음성 명령"** 과 보고서 `.claude/tasks/medreader-plan-9b-report.md`. 운영자 승인 전까지 소절 머리에 `[신설 2026-11-15 — 9b Plan, 운영자 결정 대기]`.

## 배경
spec 17-1 (2) 가 경계를 정했다: 상시 듣기 없음, **한 번 누르고 말하기**(하단 큰 마이크 64px+ · 이어폰), 고정 명령(재생/멈춤/다음/이전/다시/번역 켜기·끄기/느리게/빠르게, 나중 "여기 설명"), **로컬 매칭만(AI 호출 0)** — 아랍어(시리아 구어 포함)·영어 정규화 + 동의어 표, 인식 언어 `ar-SY` 여부 `[가정]`, 실패 시 한 번 안내. 9a 는 Plan 승인됨(17-1-1, `691c1bc` — `ui/handsfree.js`, Media Session, 무음 오디오 세션, hidden 규칙 유지)이고 **Fold 7 진단(9a-0, `dev/handsfree.html`) 결과를 기다리는 중**이라 Build 전이다. 17-1-1 13절이 9b 에 넘긴 것: 길게 누름 → 듣기(Media Session 에 길게 누름 액션 없음 — 9a-0 A 의 "길게" 기록으로 답). Nour 기기: Realme GT 7, Chrome 143, 시리아 — VPN 사용 가능성(`.claude/tasks/medreader-8k-carryover.md`). 19-1-4 R2: Nour 의 다른 시제품에서 "마이크 버튼이 반응하지 않는다"는 불만이 있었다 — MedReader 는 같은 실패를 피해야 한다.

## 따질 것
1. **지금 코드의 사실**(파일:행): `SpeechRecognition` 사용 여부(0 인지), 6-4 의 인식 관련 규칙, speaker 공개 함수(재생·멈춤·다음·이전·다시·속도)와 readalong 번역 켜기/끄기 경로, 8m 목소리 전환·8d 블록·8i-3 쪽 넘김과의 관계, 마이크 권한·`permissions` 처리 흔적.
2. **Android Chrome `SpeechRecognition` 사실**(웹 문서·Chromium 이슈, 출처와 함께; 못 찾으면 `[가정 — 실기기]`): 서버 인식 여부, `ar-SY`·`ar` 지원, 오프라인 인식(`processLocally`/온디바이스 — Chrome 버전별) 가능성, 첫 사용 권한 대화, 무음 시간 초과, 낭독 중 TTS 와의 오디오 충돌(인식 시작 전 낭독을 멈춰야 하는지), 이어폰 마이크 사용, 9a 무음 오디오 세션과의 충돌.
3. **듣기 시작 방법** 선택지(화면 마이크 단추 · 이어폰 길게/세 번 누름 · 둘 다)와 9a 버튼 대응과의 겹침, 본문 탭·길게 누르기 제스처와 겹치지 않음.
4. **명령 표**: 명령마다 아랍어(표준 + 시리아 구어 변이)·영어 동의어 초안(아랍어는 `[검토 — Nour·운영자]`), 정규화 규칙, 부분 일치·숫자("두 번 뒤로" 같은 것 받을지), 못 맞출 때 안내, 확신이 낮을 때(인식 대안 `alternatives` 활용). 영어 명령 받을지 — "명령 언어" 설정 하나.
5. **실패와 안내**: 오프라인·권한 거부·인식 서버 불가(시리아·VPN)·마이크 없음 각각 화면·소리 안내, 이어폰 버튼은 계속 됨.
6. **실기기 확인 도구**: 9a-0 처럼 `dev/` 진단이 필요한지(인식 언어·VPN 켬/끔·지연·정확도·낭독 중 충돌). 필요하면 **9b-0** 으로 나누되, 운영자 Fold 7 시험이 아직 안 됐으니 **9a-0 과 같은 왕복에 묶을 수 있는지**(같은 페이지에 묶음 하나를 더하거나 별도 페이지) 비교하고 권장 — 실기기 왕복을 줄이는 쪽.
7. 9a 와의 순서·파일 경계(`ui/handsfree.js` 를 둘이 같이 쓰는지, `voice/commands.js`·`voice/listen.js`), 수용 기준 `[N]`·`[D]`·`[M]`, headless 시험 방법(`SpeechRecognition` 흉내), 고지(13절 "음성 명령" — 음성이 인식 서버로 간다는 것), 크기·시간, 결정 표(9b-D1… 선택지·권장·이유).
