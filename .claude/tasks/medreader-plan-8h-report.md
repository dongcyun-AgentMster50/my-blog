## 설계 요약

- **A** 새 순수 모듈 `text/cite.js`: `isCitation`(A1)·`markReferences`(A2, 문단 안 최대 5문장·400자 안에서 식별자만/출판 정보만 문장으로 **닫혀야** 빼고, 쉼표로 끝난 머리는 받지 않음). `Unit.cite=true`, `seg=null`(표 안내와 같은 길) → `sentencesOf`·번역 요청·창·`readStats` 에서 저절로 빠짐. 남는 문장의 `src` 불변 → 캐시 키 불변. speaker 는 **큐에서 거른다**(`queueOf`) → 반복·step·진행 표시·쪽 넘김 수정 없음. 인용 줄 탭은 "그 줄 뒤 첫 발화"로.
- **B** `splitSentences` 에 경계 두 개(글머리 앞, 식별자 괄호 끝 뒤 + 다음 글자가 그 언어의 문장 시작 꼴). en dash 줄머리는 넣지 않음(39줄). 7c E1 테스트는 일부러 빨개짐 → 대조 사본에 B 를 넣고 "바뀐 곳은 B 경계뿐" 검사로 대체.
- **C** `speechMarks` — 원문 발화·번역문 발화 양쪽, `src`·화면 불변.
- **D** 정적 검토로 원인 후보 4개. 가장 유력: **판 섞임**(옛 index.html 에 `#trBand` 없음 → `initTrBand` 가 조용히 돌아감, 소리는 남). 재현은 8h-1 Review 브라우저 세션에서. 고치는 범위: 판 섞임이면 코드 없음(+설정에 판 표시 권장), 아니면 `reader.css` 또는 `controls.js` 한 곳.
- **E** 기록만(세 열 결함 — 14단계).
- **F** `dev/tashkeel-ab.html` — 6~8문장 × 판 3개(없음/전부/필요한 곳만) 눈가림, 낱말 칩 누르기, [결과 복사]. 글은 운영자가 `dev/tashkeel-make.mjs` 로 미리 생성(키는 환경 변수·헤더만, `assertNoKeyInUrl` 같은 검사), `stripTashkeel(부호판) === 부호 없는 판` 검증 + `countTokens`. 원서 문장은 싣지 않음(공개 페이지).
  앱 반영 추정: **전부 부호는 출력 토큰 2~3배 → 출력 상한 4,700·요청 상한 8,000 초과 → 청크 축소, 호출 약 2~2.4배.** **필요한 곳만은 +15~40% → `OUT_TOKEN_FACTOR` 3→4 로 청크 유지, 호출 거의 불변.**
- **G** `algoVersion`·`DB_VERSION`·프롬프트 버전 불변(재추출 없음). import map 재도장 필요. 테스트 T-A1·A2·B·C·U·S·R + 변이 m1~m8, 실제 책 오탐 0 기준.

## 운영자 결정 (권장안 굵게)

1. **A 범위** — **A1 + A2(참고문헌 묶음, 닫힘 조건 필수)** / A1 만(빠지는 글자가 2.72%p 줄고, 제목·학술지·"2022;40:381" 은 계속 읽힘).
2. **"인용·참고문헌도 읽기" 설정** — **둔다, 기본 끔, 켜도 원문으로만 읽고 번역하지 않음** / 두지 않음.
3. **B** — **글머리 + 식별자 괄호 끝 경계 둘 다, en dash 제외**(이미 읽은 쪽 일부 문장이 한 번 다시 번역됨 — 최대 2.5%) / 글머리만(54단위뿐이라 효과 작음).
4. **C** — **피연산자 사이만 ∗→*, 나머지 지움** / 전부 지움(HLA 대립 유전자 이름이 바뀜 — 비권장).
5. **E** — **기록만, 14단계에서** / 낭독 단계 중복 제거 규칙(책 관례 의존 — 비권장).
6. **F 페이지** — **판 3개(없음/전부/필요한 곳만) 눈가림, 운영자가 미리 생성, 직접 쓴 문장(원서 글 미수록)** / 판 2개 / Nour 키로 즉석 생성(키 표면 확대·Nour 한도 사용 — 비권장).
7. **F 반영 기준** — **8문장 중 5개 이상에서 부호판이 낫고 Q3 가 "아니요"가 아니면 별도 Plan(8h-T)** · ③(필요한 곳만)이 ②만큼 좋으면 ③.
8. **D** — **8h-1 Review 에서 재현, 먼저 Nour·운영자에게 "같은 때 리플로우에서도 띠가 없었나" 확인**.
9. **순서** — **8h-F 와 8h-1 을 동시에 시작, 8h-1 은 8g(검색) 앞** / 8g 뒤.
10. **다른 책 측정** — Build 전에 운영자가 Harrison·CMDT 2021 로 `probe-citations-8h.mjs` 실행(경로 허락).
