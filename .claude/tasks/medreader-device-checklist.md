# MedReader 마지막 실기기 점검 묶음 (한 자리에서)

> 운영자 방침(2026-11-15): "Nour 확인은 나중으로 미루고 앱을 일단 완성하자." 그래서 9a·9b·8e 는 실기기 확인 없이 기본값으로 만들었다. 이 문서는 여러 보고서에 흩어진 점검 항목을 **한 번에 하는 순서**로 모은 색인이다. 항목의 자세한 뜻은 괄호 안 출처를 본다.
> 순서: **운영자 Galaxy Z Fold 7(하루, 약 60–90분)** → 이상 없으면 **Nour Realme GT 7(아랍어 점검표 하나)**. 앱이 더 바뀌면 이 문서에 항목을 더한다.

## 0. 준비
- Chrome(메신저 안 브라우저 아님). 유선·블루투스 이어폰(가능하면 둘 다). 음악 앱 하나를 잠깐 틀었다 끈다(버튼을 가로채는지 보려고).
- 결과는 [결과 복사] 글과 캡처로 받는다. 화면 위 알림 줄의 개인 정보는 가린다.

## 2. 앱 — 이어폰·잠금 화면 버튼 (9a)
출처: `.claude/tasks/medreader-build-9a-report.md` 7절 1–13 + review.md "9a Review" 9aR 실기기 보완 8개.
- 이어폰 한 번·두 번·세 번·길게, 알림 ⏮⏯⏭·잠금 화면 단추·책 제목·"쪽 n / m", 다른 음악 앱이 안 켜짐, 10분 낭독 끊김 0, 번역 낭독 중 ⏭, 쪽 끝 ⏭(8i-3), 이어폰 멈춤 4분 뒤 재생(유지 잠금), 화면 끄면 멈춤 유지, 블루투스에서 무음이 정말 무음인지, 설정 끄면 9a 전과 같음.
- Review 보완: 서재로 나가면 알림이 사라지나, [▶] 전 이어폰이 음악 앱을 켜나, 알림 ⏯ 그림이 반대인 순간, 메신저 알림음·전화 뒤 상태, 퀴즈 [읽기] 중 이어폰, 블루투스 배터리 체감.

## 3. 앱 — 음성 명령 (9b)
출처: `.claude/tasks/medreader-build-9b2-voice-report.md` 6절 V-1~V-11(+ 9b-1 ★·9b-2 ◆), spec 17-1-2 9절.
- 설정 > 음성 명령 > [말해 보기] 로 V-1~V-4: 쓰인 인식 언어(시리아 → 요르단 → 아랍어), VPN 켬/끔(Nour), 지연 ms, 명령 9개 × 2번 맞은 비율, 부정문("don't stop"·«لا توقف»·«ما بدي ترجمة»), 두 뜻 낱말(«شغل»·«بعده»), 확신도가 1.0 으로 채워지나.
- 리더에서 V-5~V-10: 낭독 꼬리가 인식에 섞이나, 명령 뒤 이어 읽기, 실패 안내 한 마디, 이어폰 마이크, 듣는 중 이어폰 ⏯, 첫 권한 대화·거부·비행기 모드·다른 앱 마이크 사용 중, 이어폰 길게(9b-3 근거), 듣는 중 화면 끄기.
- V-11 접은·펼친·가로 화면에서 마이크 단추·고지 카드.
- `[9b-2 Review 9b2R-8 · 9b 다듬기 뒤]` 더할 것 5개(출처 review.md "9b-2 Review" 9b2R-3·9b2R-8):
  1. **V-4 ◆ 대안 목록의 부정어** — [말해 보기] 대안 목록에서 ① 부정문("don't stop"·«لا توقف»)의 **첫 대안이 부정어를 잃고 아래 대안만 부정어를 지니나**(그러면 지금 규칙 Rb 로는 반대 동작 — 더 엄한 Ra 가 필요한지) ② **부정하지 않은 명령**(«توقف»·"next")의 **아래 대안에 «لا»·«ما»·"not" 이 끼나**(Ra 로 바꿀 때 잃는 명령의 양). 둘 다 [결과 복사]로.
  2. **V-4 ◆ 반대 뜻·부정 꼴·새 낱말** — "too slow"·«كتير بطيء»(이제 실행 0 이어야) · «بلاش توقف»·«لأ كمل»(실행 0) · 표준 명령형 «أوقف»(멈춤) · "stop the translation"(번역 끄기) · 짧은 의학 구 «المريض التالي»·«قلبه وقف»(옆 사람 말이 8초 안에 들어와 명령이 되나).
  3. **V-7 ◆ 듣는 중 이어폰** — 듣는 중·안내 중 이어폰 ⏯ 은 "곧장 읽기"가 된다(듣기 때문에 멈춰 있어 토글이 재생). 듣는 중 이어폰 다음/이전 → 멈춘 채 한 칸(읽기가 이어지지 않음). 사용자가 놀라지 않는지.
  4. **V-7 ◆ 오디오 포커스** — 인식기가 오디오 포커스를 잡을 때 Chrome 이 Media Session `pause` 같은 액션을 스스로 보내 **듣기가 저절로 취소되지 않나**(9a 핸들러 첫 줄 취소와 맞물림 — headless 로는 못 봄). 증상: 마이크를 눌러도 곧바로 듣기 표시가 꺼짐.
  5. **V-11 ◆ 가로 고지 카드** — 9b 다듬기 뒤 가로 카드는 화면 폭까지 넓고, 높이는 바 위에서 자르지 않는다(9b 다듬기 Review 중-1). headless 실측: 915×412 는 바와 떨어져 겹침 0, 그보다 낮은 가로 높이(740×360 등 — 실제 Chrome 은 주소창 때문에 대략 330–360)에서는 **고지 글은 100% 보이고 카드가 바·마이크를 잠깐 덮는다**(9b-2 와 같은 동작). 실기기에서 볼 것: 고지 글("Google 서버로 갈 수 있다")이 다 보이나, [시작]·[취소]가 손가락으로 눌리나, 카드를 닫은 뒤 마이크가 그대로 눌리나.
