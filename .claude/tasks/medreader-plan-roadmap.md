## 오케스트레이터 판단 — spec 에 반영할 것

### A. 전제 갱신 (1절·13절·16절 표기)
- **비용 0원은 최소 1년간 절대 조건**이다. 유료 대안은 로드맵에서 뺀다. 8-2·19절 "지역 제한 시 대안"의 ② "비용 확인 후 Grok" → "**무료 티어가 있을 때만**"으로 바꾸고, 18절에 근거(요구 6) 한 줄.
- **무료 한도가 가장 귀한 자원이다.** 호출을 쓰는 새 기능은 전부 "1만 자당 호출"을 낭독 동반 번역과 나눠 쓴다는 것을 17절 머리에 원칙으로 적어라. **여러 무료 프로바이더를 이어 쓰기**(Gemini 한도 소진 → 사용자가 넣어 둔 다른 무료 BYOK 키로)를 10단계 어댑터 작업의 목적으로 명시하라. 같은 프로바이더 키 여러 개 돌려쓰기는 약관 위반 소지가 있으니 **하지 않는다**고 적어라.
- **VPN**: Nour 는 VPN 으로 AI 사이트를 쓴다. 앱은 VPN 사용을 **안내·권장하지 않는다**(`REGION` 문구는 "키 문제가 아니다, 네트워크 위치 때문일 수 있다"까지). 16-D0 `[M]` 실호출 기록에 **VPN 켬/끔을 함께 적는다**는 줄을 더하라 — VPN 이 켜져 있으면 결과가 시리아를 뜻하지 않는다. (16-D0 의 나머지 내용은 바꾸지 마라.)
- **기기**: Nour 가 "새 휴대폰"을 쓴다. 1절·16절의 "Realme GT7T" 를 "Nour 의 기기(모델 확인 필요)"로 바꾸고 `[가정]` 표시.

### B. 로드맵 재정렬 (17·19절) — 8단계 이후 순서를 다시 짠다
제안 순서와 근거를 19절에 표로. 각 단계에 "무료 한도를 쓰는가"·"오프라인 가능"을 열로 둬라.

1. **핸즈프리(음성 명령) — 17 #22 를 P3 에서 8단계 바로 뒤로 올린다.** 요구 1 의 "필수". 설계 경계:
   - **명령은 적고 고정**: 재생/멈춤/다음/이전/다시/번역 켜기·끄기/느리게/빠르게/여기 설명(나중). 아랍어·영어 키워드를 **로컬 매칭**(AI 호출 0). AI 의도 해석은 넣지 않는다(한도 절약).
   - **상시 듣기는 하지 않는다**: 낭독 음성이 마이크로 들어가 자기 명령을 듣는 문제, Android Chrome `SpeechRecognition` 이 서버 인식(네트워크·VPN 영향 `[가정]`)이라는 점(6-4). **한 번 누르고 말하기**(화면 아무 곳 크게 + 이어폰 버튼)를 기본으로.
   - **이어폰·잠금 화면 버튼**(Media Session API: play/pause/nexttrack/previoustrack)으로 재생·멈춤·다음·이전 — 말하지 않아도 되는 가장 싼 핸즈프리. `speechSynthesis` 는 미디어 세션을 갖지 않으므로 무음 오디오로 세션을 잡아야 할 수 있다 `[가정]` — 실기기 확인 항목으로.
2. **설명·요약 — 사용자 재결정이 필요한 항목으로 보고서에 올려라.** 2026-09-28 에 요약은 NotebookLM 과 겹친다는 이유로 후순위가 됐다. 요구 2 는 앱 안에서의 **설명·요약**을 명시한다. 권장안: 8b 이후 **"이 문장/문단 설명"**(음성 명령 "설명해줘"로도)을 먼저, 문단 요약은 그다음 — 둘 다 낭독 흐름 안에서 **사용자가 부를 때만**(자동 호출 없음). 네가 결정하지 말고 선택지·권장안·한도 영향을 적어라.
3. **핵심 기억(SRS)** — 17 #16. 번역·설명된 문장에서 카드를 만든다(추가 호출 없이 캐시 재사용 가능한지 검토).
4. **마감 전 검토** — 17 #20 플래너 + #14 진도. "시험일까지 남은 글자 ÷ 하루 낭독 시간"을 보여 주는 정도(순수, 호출 0).
5. **개념도** — 17 #21. 호출을 쓴다 — 후순위.
6. **학술 언어 학습** — 17 #18·#19. 시험 이름은 Nour 에게 확인 필요(`[미정]`). 요르단·레바논 이동 목적의 국제 언어 시험이라는 것만 적어라.
7. **의료 웹사이트 접근** — 13절 그대로 **딥링크 모음만**(계정 정보 저장 안 함). 사용자가 링크를 추가·수정할 수 있는 북마크 목록이면 충분하다.

### C. spec 에 없던 것 — 새로 넣는다
1. **스캔본 PDF(OCR)** — 요구 4 "스캔 자료". 지금 추출은 텍스트 PDF 전제다(텍스트 0인 쪽은 읽지 못한다). 선택지를 비교만 하라: (a) 브라우저 OCR(예: Tesseract.js — CDN 은 웹앱에서 허용. 영어·아랍어 언어 데이터 크기·속도 `[가정]`), (b) Gemini 비전으로 OCR(**무료 한도를 크게 먹는다** — 쪽당 이미지 1회), (c) 미지원 + 안내. 권장안과 위치(로드맵 몇 번째)를 적어라. 설계 상세는 하지 않는다.
2. **의료 사례 이미지** — 17 #23 Open-i(교육용 참조 이미지 검색)로 받는다. **판독 기능은 여전히 없다**(13절 의료 안전) — 요구 4 를 받아도 이 경계는 유지한다고 18절에 한 줄.
3. **데이터 백업·옮기기(내보내기/가져오기)** — 요구 7 의 답의 일부이자 **새 휴대폰** 때문에 필요하다. 지금 모든 데이터(서재 PDF·추출본·진도·번역 캐시·퀴즈 기록)는 **한 브라우저의 IndexedDB 에만** 있다 — 기기를 바꾸거나 브라우저 데이터를 지우면 전부 사라진다. 백업 파일 하나로 내보내고 새 기기에서 가져오는 기능을 로드맵 **앞쪽**(핸즈프리와 비슷한 우선순위)에 두고, 무엇을 담을지(PDF 원본은 크므로 선택, 추출본은 `algoVersion` 이 같으면 재사용, 키는 **절대 담지 않음**)를 경계로 적어라.
4. **자료 추가·수정**(요구 7) — 이미 되는 것과 아닌 것을 17절에 정리: 새 PDF 가져오기(됨), 앱 기능 갱신은 배포로 자동(사용자 데이터는 유지), 필기·하이라이트(#17, 미구현), 의료 사이트 링크 목록(B-7), "API 로 연결·다운로드한 자료"(요구 2)는 **PDF 로 받아 가져오기**가 경로 — 외부 사이트 자동 수집은 하지 않는다(13절 스크래핑 금지).
