- 외부 링크 장치는 정보 화면 하나(`js/main.js:305-310`, `noopener noreferrer`).
- 검색 주소 확인(2026-11-16 직접 조회): MedlinePlus·PubMed·Wikipedia(아랍어 언어 링크 있음)·DailyMed 는 `{q}` 로 결과가 나옴. MSD Manual·Radiopaedia·NCBI Bookshelf 는 비대화 조회로 확인 못 함, UpToDate `search=` 꼴은 도서관 예시 하나뿐 → `[확인 필요]`.

**9c — 백업·옮기기**
- 내보내기·가져오기 코드 0. DB 3, 스토어 14개. 키는 DB·settings 밖(`keys.js:43`).
- **결함 둘(지금은 드러나지 않음)**: (1) 같은 PDF 재가져오기 경로가 `blobs` 를 쓰지 않는다(`library.js:427-445`) — 백업에서 복원한 "PDF 없는 문서"에 PDF 를 붙일 길이 없다. (2) blob 없는 문서를 열면 `openDoc` 이 `null` → 리더가 조용히 빈다(`library.js:818-836`).
- 캐시 키에 `docId` 가 들어 있다(`kind|target|docId|해시`) → 다른 `id` 로 복원하면 키를 고쳐 써야 한다. 캐시 값에는 원문 문장이 없다(번역문만).
- 캐시 크기 수는 메모리에 있어 DB 를 직접 쓰면 어긋난다 → 가져온 뒤 다시 불러오기.

**10 — 다른 무료 번역 서비스**
- 어댑터는 gemini 하나(`provider.js:29-32`). 키 저장은 이미 프로바이더별, 캐시 키에 프로바이더 없음(바꿔도 캐시 유지), `usage.byProvider` 있음.
- 파이프라인 상태 기계가 **한 벌**(`pipeline.js:142-236`) — 이어 쓰기에는 프로바이더별 상태가 필요. 모델 설정도 하나(`ai.model`).
- 동의 문구는 회사 이름 없는 "외부 API"(`i18n/ko.js:50-51`).

## 2. 뼈대 요약

- **18-1 (Build 하나)**: `links.medical`(null = `config.js` 기본 목록) · 순수 `text/links.js`(https 만, `아이디:비번@` 거절, `{q}` = `encodeURIComponent`, 6낱말·60자) · 서재 아래 접는 카드(열기) + 설정 카드(추가·수정·순서·삭제·추천 추가·기본으로) · 선택 동작 줄 `[찾아보기]` 하나(링크 하나면 바로, 둘 이상이면 작은 목록), 새 탭 `noopener noreferrer`. 호출 0, DB 무관.
- **9c (세 Build)**: 한 파일 **NDJSON + gzip**(머리 줄·레코드 줄·끝 줄 — 잘린 파일 감지). 담는 것 = 문서 메타(사용자 몫)·진도·퀴즈 기록·단어장·필기·사용량·설정(허용 목록 — 목소리 URI·동의·키 기억 제외)·번역 캐시(기본 켬). **추출본·검색 글자·원서 문항은 안 담음**(무료 재추출), PDF 는 책별 `.pdf` 따로 내려받기. 가져오기 = **병합만·지우지 않음·멱등**, 같은 `fileHash` 문서가 있으면 그 `id` 로 바꿔 씀(캐시 키 셋째 칸 등), 500줄씩 트랜잭션, 끝나면 다시 불러오기. 메모리: 내보내기는 1,000줄씩 Blob 이어 붙이기, 가져오기는 흐름 읽기. "PDF 필요" 서재 상태 + `[PDF 가져오기]`(해시·쪽수 확인). 키 0건은 정적 시험(`backup/*` 가 `privacy/` import 0) + 가짜 키 grep.
- **10 (운영자 결정 뒤)**: `openai-compat` 어댑터 하나(매개변수) · `ai.chain` 순서 · 프로바이더별 키·모델·동의 · `exhausted`/`region` 일 때만 넘어감(묻기/자동은 운영자) · 상한은 합 · 넘어간 뒤 같은 청크는 "첫 전송"(자동 재시도 0 유지). 새 서비스 없는 대안 **(G) 같은 Gemini 키·다른 모델 사슬**.
