## 3. 채점 정의 (`measure-table-8i4.mjs score`)

- **표 판정**: 정답 띠의 y 범위와 겹치는 예측 표가 있으면 "표". 정밀도 = 맞힌 표 / 예측 표. 재현율·정확도 함께.
- **표 아님 오탐**: 정답이 "표 아님"인 띠에서 예측된 표 + 표 아님 쪽 목록에서 예측된 표(띠 수). 문턱 0.
- **행**: 정답 표의 행마다 (첫 줄, 끝 줄)이 예측 행과 3pt 안에서 같으면 맞음. 예측 행 + 바로 뒤 **하위 행**(행 머리 칸 빈 행, T4 가 앞 행 머리를 물려 읽음) 묶음도 한 행으로 인정. 위첨자만 든 줄은 줄로 치지 않음. **놓친 표의 행은 전부 틀림**(엄격) — "잡힌 표만" 값도 따로 낸다.
- **칸**: 정답 범위(머리 줄·합친 칸 줄 뺌)의 조각 — 규칙과 무관하게 아이템 틈 ≥ 0.3em 로 나눔 — 글자 가중. 정답 칸 k 와 예측 칸 j 가 서로 최다 짝이면 맞음, 정답 경계를 1·Fm 넘게 가로지르는 조각은 틀림. 예측 칸은 예측이 실제 쓴 단위(T6 면 조각, 아니면 앱 run)의 가운데로 정한다.
- **머리**: 정답 표의 칸마다 머리 글 앞 10자(영숫자 소문자) 같음 · 둘 다 없음이면 맞음.
- 문턱: 정밀도 ≥ 95% · 표 아님 오탐 0 · 행 ≥ 95% · 칸 ≥ 95% · 머리 ≥ 90% — **엄격 값으로 판정**.

## 6. 판정 — 무엇이 모자란가

문턱 5개 중 **정밀도·오탐 0 은 넘고, 행·칸·머리(엄격)는 넘지 못했다.** 잡힌 표만 봐도 행·칸이 95% 아래다. 모자란 것은 셋이다.
1. **오탐 0 과 재현율이 맞바뀐다.** 텍스트 좌표만으로 그림·흐름도·서식·다단 산문을 막는 가드(G1 정렬·맞물림·채움, G2 목록, G5 머리)는 긴 비고 칸 표·작은 표·글머리표 칸 표도 같이 막는다(시험 3/5). 개발 표본에 이런 표가 없어 문턱이 개발에만 맞았다.
2. **띠 경계를 텍스트만으로 못 정한다.** 표 밑 산문이 넓은 줄 없이 이어지는 경우(C477), 설명 칸 줄이 거의 다 넓은 2열 표(C695·C1110), 칸을 가로지르는 합친 칸(dev C586)은 띠·통로 단계에서 이미 무너진다.
