- **요약·설명 경로는 아직 없다.** `prompts.js:386-387` 에 "요약 프롬프트 자리" 주석만, `explain` 은 음성 명령 표에 `enabled:false` 로 자리만(`voice/commands.js:138-144` → `ui/voice.js:307-311` "아직 없는 기능").
- **파이프라인은 번역 전용이다** — `sendChunk`/`accept`/캐시 판정이 `buildTranslateRequest`·`TRANSLATE_SCHEMA`·`checkTranslation`·"결과는 문자열"에 박혀 있다(`pipeline.js:244-410·472-555`). 8f-1 이 `job` 주입으로 일반화할 예정(8cf 초안) → 11 은 그 위에 요약·개요·설명 job 셋을 얹는다.
- **캐시 키는 그대로 쓸 수 있다** — `cacheKindOf` 가 `translate`/`readalong` 만 접고 `summarize`·`explain` 은 그대로(`cache.js:33-40`). `usage.byKind.summarize` 는 이미 고정 키, `explain` 은 `READALONG_KIND` 처럼 따로 둬야 7a 빈 행 시험이 안 깨진다(`config.js:631-643`·`provider.js:262-266`).
- **`annotations` 스토어는 있고 아무도 안 쓴다** — 인덱스 `docId_pageNo`·`docId`·`kind`(레코드 맨 위에 `docId`·`pageNo` 가 있어야 인덱스에 잡힘), 문서 삭제 연쇄에 들어 있음(`db.js:84-89·451-454`). DB 버전 3 그대로 충분.
- `tts.autoSummarize`·`ai.summaryLangs(['ar','en'])` 는 읽는 코드 0(`settings.js:59·95`). `ai.summaryLangs` 는 언어를 박아 7-1 원칙 5 와 어긋난다.
- 문단 id 는 `쪽:p순번`(`blocks.js:641`) — 다시 추출하면 바뀔 수 있어 저장 요약은 문단 글 해시로 다시 찾는다.
- 문장 목록 `sentencesOf(units)` 가 인용·표 안내를 이미 뺀다(`tts/text.js:472-505`) → 요약 입력 = 그것을 문단별로 이은 글(분할 한 벌 유지).
- 대상 언어 글을 소리 내는 도우미가 없다 — 9b `say` 는 i18n 키만(`ui/voice.js:194-220`). 새 `tts/say.js` 필요.
- 선택 동작 줄은 8c-1 이 만들 예정이고, 18 이 `[검색: …]` 을 더하며 "넘치면 11a Plan 이 `[⋯]` 를 정한다"고 넘겼다.

## 2. 뼈대 요약

- **요약(11b)**: 요청 한 번에 문단마다 **요지(대상 언어) + 원문 언어 요지 + 요점 2단 + 용어**를 받는다 → 같은 응답으로 글과 **글 트리(11c)**를 그린다(호출 추가 0). 언어 = 대상 + 문서 원문 언어(`ai.summaryLangs` 안 씀). 지시문은 10-1 규칙 1–6 글자 그대로 + 8p `domain`. 키 `summarize|target|doc|hash(문단 글)|l=ar+en` — 한 문단 요약과 [이 쪽 전체 요약]이 같은 키라 쪽 요약 뒤 개별 문단은 0회. 출력 숫자가 입력에 없으면 그 요점을 뺀다(지어낸 용량 거름).
- **입구**: 선택 동작 줄 `[⋯]` → [요약] · 음성 새 명령 "요약"(«لخص»/summarize — 문단 첫 문장에서 말하면 방금 읽은 앞 문단). 7-3 의 문단 끝 칩은 만들지 않는다(본문 위치를 흔든다).
- **보기**: 8f-2 단어 시트와 같은 자리·높이의 요약 시트 — 요지 두 언어, `<details>` 접는 트리, 용어, 고지 한 줄, [저장]·[▶ 듣기]·[이 쪽 전체 요약 (문단 n · 호출 k)]·[다시 요약].
- **저장**: `annotations` `kind:'summary'`(문단·대상 언어당 하나, 다시 저장은 대체). **문서를 지워도 남는다**(단어장과 같음).
- **모아 보기·11c 범위 개요**: `#/summaries/:docId` — 장/쪽 순 목록, [원문으로], 삭제, `.txt` 내보내기. 범위(장·쪽)를 골라 **저장한 요약만**을 입력으로 한 번 호출 → 3단 개요 트리, `kind:'outline'` 로 저장(16 그림 개념도의 입력).
- **설명(11a)**: 선택 줄 [설명](보이는 셋째 칸) · 음성 "설명" 켬. 맥락 = 문장 + 그 문단(≤1,500자), 결과 ≤3문장·400자. 부르면 낭독을 멈추고 → 띠 "설명" 모드에 글 + 대상 언어 음성 → 읽던 중이었으면 이어 읽기. 키에 문단 해시 앞 12자. `byKind.explain`.
- 새 파일: `text/summary.js`(순수) · `notes/summaries.js`(서비스) · `ui/sumsheet.js` · `ui/tree.js` · `ui/ask.js`(흐름) · `tts/say.js`(대상 언어 한 마디) · `ui/summaries.js`. DB 버전·`algoVersion`·번역 `PROMPT_VERSION` 무변, 새 판본 상수 셋(값에만).
