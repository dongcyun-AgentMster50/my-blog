**규칙(정확한 꼴)**
- (가) `^(\d{4}) (?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec)\.?(?: \d{1,2})?;` — 연도 **바로 뒤**, 문장 맨 앞에서만. 걷어 내면 `연도;` 가 남는다.
- (나) `:e(?=\d)` — 콜론 **바로 뒤** 소문자 `e` 하나(뒤가 숫자일 때만). 범위 끝의 두 번째 `e`("e38–e360")·대문자 `E`·`: e123`(공백)은 걷지 않는다 → 글자로 남아 읽는다.
- 그 밖의 글자는 여전히 불허(`ANY_LETTER`). "바로 다음 문장이 식별자만(A1 `'id'`)" 닫힘 조건·`publicationTails`·`markReferences`·A2 `PUB_ONLY` 는 그대로.
- A2 닫힘 `PUB_ONLY` 와의 관계: A2 는 월 자리에 "대문자+소문자 2자"(아무 3글자 낱말, 마침표 없음)를 받는다. A3 는 그보다 **좁게** 12개 월 약어만 받고, spec 대로 마침표만 더 허용한다("2019 Jan. 5;…"). A2 정의는 건드리지 않았다.

## 3. 변이 (실행기: 대상 1건 확인 → 적용 → 적용 grep → 전체 테스트 → 스크래치패드 복사본으로 복원 → `cmp`)

IM2·IM6·IM7b(importmap 해시)는 cite.js 를 바꿀 때마다 함께 빨갛다 — 아래 표는 그 셋을 뺀 것. 모든 회차 복원 `cmp` 같음, 끝에 작업 트리 `cite.js` = 넓힘 판(`cmp`).

| # | 변이 | 적용 grep | 빨개진 테스트 |
|---|---|---|---|
| M1 | 월 목록 → 아무 낱말(`\p{L}+`) | 1 | T-A3 `isPublicationOnly` · T-A3 ★ 음성(낱말이 섞인…) · **T-A3w ★ 음성** |
| M2 | `e` → 아무 글자(`:\p{L}(?=\d)`) | 1 | **T-A3w ★ 음성** |
| M3 | 일 1–2자리 → 1–3자리 | 1 | T-A3w ★ 음성 |
| M4 | 콜론 뒤 공백 허용(`:\s?e`) | 1 | T-A3w ★ 음성 |
| M5 | 월 걷기 없앰 | 1 | T-A3w ★ 양성 |
| M6 | `e` 걷기 없앰 | 1 | T-A3w ★ 양성 |

- 기록: M5 첫 시도는 실행기가 node `String.replace` 를 써서 바꿀 글자의 `$&` 가 특수 패턴으로 해석돼 파일이 깨졌다(전 파일 로드 실패). 복원 `cmp` 는 같았고, 실행기를 `split/join` 으로 고쳐 M5·M6 을 다시 돌린 위 결과가 유효하다. M1–M4 는 바꿀 글자에 `$` 가 없어 영향 없음.
