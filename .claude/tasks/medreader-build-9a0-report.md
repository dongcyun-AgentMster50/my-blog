실패 10개:

- **새로고침 뒤 기록 유지 2건** — 기대 3회인데 9회로 나왔다. 기록은 남았지만, 앞 패스의 기록이 섞여 이 검사는 기대대로 확인되지 못했다.
- **판정 분기 8건** — 시험이 넣은 기록을 페이지의 `pagehide` 저장이 덮어쓴 것으로 **코드를 읽고 추정**했다. 고친 스크립트로 다시 돌려 확인하지는 못했다.
- 같은 판정 묶음의 **통과 3건(C 끊김·B 간격 큼·B 공백 큼)도 믿을 수 없다** — 같은 이유로 앞 시험의 남은 기록을 읽어 우연히 맞았을 가능성이 크다. 따라서 **판정 11개 분기는 사실상 미검증**이다. 다만 `SESSION='none'` 후보·C 보류·B 3분 미달 줄이 실제 출력에 나온 것은 보았다.

그 밖의 한계:

- **권한 막힘 뒤 고친 한 줄**: `run.cut` 조건을 spec 대로 `interrupted` 외 오류만 세도록 바꿨다(그 전에는 `canceled` 도 뺐다). 이 줄 이후 브라우저 검사는 돌지 않았다.
- **실제 낭독은 시작만 확인**: headless Edge 에서 음성 7개, 첫 `start` 기록까지. 사슬 전체는 가짜 synth 로만 봤다.
- **데스크톱 툴바 미디어 컨트롤**: headless 라 못 봤다 → Review 로.
- **Android 동작은 아무것도 재지 못했다**: 알림·이어폰·포커스·화면 꺼짐은 전부 실기기에서만 나온다.

정리 상태:

- Edge 는 스크립트 끝의 `browser.close()` 로 닫았다. 다만 **이 프로필의 잔여 프로세스가 없는지는 확인하지 못했다**(그 조회가 막힌 명령에 들어 있었다). 전체 `msedge` 6개가 보였는데 사용자 것인지 구분되지 않는다.
- PID 45964 는 없어서 8000번 python 을 새로 띄웠다(**PID 32256**, 끄지 않았다). 8123–8125 는 건드리지 않았고 처음부터 듣고 있지 않았다.
- 프로필은 `scratchpad/b9a0/profile` 1개, 복사 없음. 스크립트와 출력은 `check.cjs`·`out.txt`.

## 4. 막힌 것

**막힌 명령**: 한 Bash 호출에 묶은 세 동작 — ① `check.cjs` 수정(패스 시작을 [기록 지우기]로 바꾸고, 가짜 패스에서 `pagehide` 를 막음) ② `check.cjs` 재실행 ③ PowerShell `Get-CimInstance` 로 `b9a0` 프로필의 Edge 프로세스 세기.

**사유**: 자동 모드 분류기 `[Auto-Mode Bypass]`. 세 동작 중 어느 것 때문인지는 알 수 없다. **아무것도 실행되지 않았고**, `check.cjs` 도 고쳐지지 않았다.

지시대로 나눠 돌리거나 다른 명령으로 바꾸지 않고 멈췄다. 선택지:

1. 운영자가 재실행을 허용한다 — ①②만 다시 돌리면 판정 분기까지 끝난다.
2. Review 가 판정 분기를 맡는다.

## 5. Fold 7 점검 순서 (운영자)

준비: 배포 뒤 Chrome 으로 `…/apps/medreader/dev/handsfree.html`. 음악 앱을 잠깐 틀었다 끈다(버튼이 그 앱으로 가는지 보려고). 이어폰 이름을 적는다.

2. **A2**(모드 2) — 같은 순서 + 알림창 ⏮⏯⏭ + 화면을 끈 뒤 잠금 화면 단추.

6. **C** — 2분 듣기만. 끊기면 [낭독이 끊겼어요!]. 2분이면 저절로 끝난다.
7. **D** — 알림창 캡처 → [문장식 막대] → 다시 캡처, 2장.

## 6. Nour 점검표 초안 (운영자가 아랍어로 옮길 것)

> **spec 뼈대와 다른 점**: 앞에 1번(모드 1)을 더했다. 판정 규칙의 `SESSION='none'` 이 "두 기기 모두"여서 Nour 의 모드 1 결과 없이는 판정할 수 없다. 묶음 C·D 는 뼈대대로 뺐다 — 그래서 Nour 결과의 "C 안 함"은 정상이다. 다만 포커스 다툼 판정은 Fold 7 값뿐이다.

1. Chrome 으로 `…/apps/medreader/dev/handsfree.html` 을 연다(메신저 안 브라우저 말고). 이어폰 이름을 적는다.
2. [A1] 을 누른다. 영어 문장이 들리면 유선/블루투스를 고르고, [Once] 누르고 이어폰 단추 한 번, [Twice] 누르고 두 번, [3 times] 누르고 세 번. 끝나면 [Stop]. 다른 음악 앱이 켜지면 [A music app started].
3. [A2] 를 누르고 2번처럼 이어폰을 누른다(아직 [Stop] 은 누르지 않는다). 화면의 "Buttons received" 숫자가 늘어나는지 본다.
4. **[Stop] 을 누르기 전에** 알림창을 내려 단추가 보이면 캡처한다. 그다음 [Stop]. ([Stop] 뒤에는 알림이 사라진다.)
5. **화면에 다음이 A3 라고 나와도 B2 를 누르세요.** [B2] 를 누르고, 전원 단추로 화면을 끄고 3분 기다린 뒤 켠다. 3분 내내 낭독이 들렸으면 [I heard it the whole 3 minutes] 를 누른다.
6. [Copy results] 를 눌러 그대로 보낸다. 복사가 안 되면 글상자가 뜨니 길게 눌러 복사한다. **낭독이 3분 내내 들렸는지(끊겼다면 언제쯤인지)도 메시지로 알려 준다.** B2 까지면 끝이다 — 화면이 다음 시험을 가리켜도 더 하지 않아도 된다.

영어 문구는 Chrome 언어가 한국어가 아니면 큰 글자로 나온다.
