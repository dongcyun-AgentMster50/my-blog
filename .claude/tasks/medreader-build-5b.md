# Build 지침 — MedReader 5b단계: 속도 단계화 + 속도 표시 동기화 + 반복 재생

## 배경

1~5단계 완료·배포됨. 사용자가 갤럭시 Z Fold 7 에서 실제로 낭독을 쓰며 준 피드백 셋을 고친다.
배포본: https://dongcyun-agentmster50.github.io/my-blog/apps/medreader/index.html

**곧 7000쪽 실제 자료로 교체된다**(형식 유사). 특정 서적 튜닝은 하지 마라.

> 하이라이트 색 섞임(`is-done` + `is-current` 동시 적용) 문제는 **오케스트레이터가 이미 고쳤다.**
> `css/reader.css` 의 `.reflow .line.is-done:not(.is-current)` 가 그것이다. 건드리지 마라.

## 고칠 것 셋

### ① 속도를 계단식으로 — 사용자 지정 값

지금은 연속 슬라이더(0.5~2.0, 0.1 단계)다. **다음 6단계로 바꾼다:**

```
0.5   0.75   1.0   1.25   1.5   1.8
```

사용자 말 그대로다: "계단식으로 해보자 0.5, 0.75, 1, 1.25, 1.5, 1.8 이렇게 있음 충분해".
`config.js` 의 `TTS` 에 상수로 두고, 기존 값이 목록에 없으면 **가장 가까운 단계로 맞춘다**(옛 설정 호환).

### ② 팝업의 속도 숫자와 컨트롤 바 버튼의 속도가 어긋난다 — 버그

`[실기기 캡처]` 팝업은 **1.0×** 인데 컨트롤 바 버튼은 **0.7×** 였다. 같은 값을 보여야 한다.
**한 곳에서 읽어 양쪽을 그리도록** 고쳐라. 어느 쪽이 옛 값을 들고 있었는지 원인을 찾아 보고하라.

### ③ 반복 재생 — 신규 기능

사용자 요구: **"한 문장 혹은 구간 반복 가능하게(횟수도 정할 수 있게)"**

- **한 문장 반복**: 현재 발화를 N번 반복한 뒤 다음으로 넘어간다.
- **구간 반복**: 시작 줄과 끝 줄을 정해 그 구간을 N번 반복한다.
- **횟수**: 2·3·5·무한 정도면 충분하다. 무한은 사용자가 끄기 전까지.
- 반복 중임을 **컨트롤 바에서 알 수 있어야** 한다(예: `2/3회`).
- 반복을 끄면 원래 흐름으로 돌아간다.

UX 는 네가 정하되 **기존 컨트롤 바가 이미 좁다**(이전·재생·다음·속도 + 진행 표시, 하단에 쪽 이동 바와 고지 바가 쌓여 있다). 버튼을 무작정 늘리지 말고 **속도 팝업 안에 넣거나 길게 누르기** 같은 방법을 고려하라. 접은 화면(약 375px)에서 넘치면 안 된다.

## 반드시 지킬 것

- **spec 6-4 의 Android 대응을 깨지 마라.** 반복은 `cancel()` + 재생으로 구현하고 `speechSynthesis.pause()` 를 쓰지 마라. **cancel 후 60ms** 규칙, utterance 모듈 변수 유지, **워치독**을 반복 경로에서도 지켜라 — 반복 중 `onend` 가 유실되면 그 자리에서 영영 멈춘다.
- **세대(gen) 검사**가 이미 있다. 반복이 그 장치를 우회하지 않게 하라.
- CSS 는 **논리 속성만**(`left`/`right`/`margin-left`/`margin-right`/`padding-left`/`padding-right`/`border-left`/`border-right`/`text-align:left|right` **0건**, 16-H).
- 문구는 전부 `data-i18n`/`t()`. 키를 추가하면 **4개 언어 전부**(`tests/i18n.test.mjs` 가 검사).
- **서비스 계층은 UI 문자열을 만들지 않는다**(3-2). `speaker` 는 코드·이벤트만.
- 터치 타깃 48px 이상(16-G). **접은 화면 375px 에서 컨트롤 바가 넘치면 안 된다.**

## 테스트

`speechSynthesis` 는 Node 에 없다. **순수하게 떼어낼 수 있는 것을 떼어내라**:
- **속도 단계 목록과 "가장 가까운 단계로 맞추기"**(옛 값 0.7 → 0.75 같은 경우).
- **반복 상태 기계** — 남은 횟수 감소, 구간 끝에서 시작으로 되감기, 무한 모드, 반복 해제 후 원래 흐름 복귀. `speechSynthesis` 스텁을 주입해 전이를 검증하라.
- 속도 표시 동기화 — **한 곳에서 읽는다**는 것을 단위 테스트로 고정하라.
- 기존 261개 전부 통과.

## 스모크 테스트

`preview_start {name:"blog"}` → `http://localhost:8000/apps/medreader/index.html` (**새 탭** — 모듈 캐시).
브라우저로 22.7MB 실물 PDF 를 넣는 것은 막혀 있다. **합성 문서를 `toStored` → `db.put` 으로 심어라**(우회 금지).

1. `node --test "apps/medreader/tests/*.test.mjs"` 전부 통과.
2. 속도 6단계가 순서대로 돌고, **팝업 숫자와 컨트롤 바 버튼이 항상 같은 값**을 보인다. 새로고침 후에도 유지.
3. **한 문장 반복** — N번 반복 후 다음으로 넘어간다. 컨트롤 바에 남은 횟수가 보인다.
4. **구간 반복** — 시작·끝을 정해 N번 돈다. 구간 끝에서 시작으로 되감긴다.
5. **무한 반복**을 켜고 끄면 원래 흐름으로 돌아간다.
6. **`onend` 유실 상황(`simulateStall`)에서 반복이 멈추지 않는지** — 워치독이 반복 경로에서도 도는가. ← **가장 중요하다.**
7. CSS 물리속성 grep 0건, **375px 에서 컨트롤 바 가로 넘침 0**, 콘솔 에러·경고 0건.
