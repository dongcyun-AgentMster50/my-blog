## O1 — 스캔본
- 감지(8l, `text/scan.js` 순수): `probePages`(10–90% 고르게 12쪽) → 글자만 셈 → 75% 이상 글자 0 이면 그중 2쪽만 이미지 확인 → `scan`/`notext`/`text`. 문서당 한 번, `documents.scan` 에 `db.patch` 자기 필드만. DB 버전·algoVersion 무관.
- 안내: 서재 카드 배지 · 리더 띠 문서당 1회 [원본 보기] · 빈 쪽 안내 문구 교체 + [원본 보기](모든 문서) · ▶ 를 눌러도 20쪽을 말없이 넘기지 않음(지금은 넘긴다 — 발견) · 검색 화면 문구. 네 언어 문안 spec 17-5-1 3.
- PC OCR 안내: 앱엔 한 문장, 명령(`py -m ocrmypdf -l eng --skip-text --rotate-pages --deskew --oversample 300 --output-type pdf`)은 spec·운영자 가이드에. 17-6 A 갱신 — PC 일괄 OCR 은 OCRmyPDF로 비용 0.
- (a) 브라우저 OCR: **앞당기지 않음**. 휴대폰 쪽당 10–30초 `[가정]`, OCR 결과 저장·재추출 분기 비용. 15단계 시작 조건을 "Nour 에게 스캔 자료 + PC 경로 없음"으로 좁힘.

## O2 — 영한 혼합
- 문서 속성 유지 + **글자 체계 덩어리 다수결**(한글→ko, 아랍→ar, 라틴→문서 언어 또는 en, 그 밖 체계는 중립, 2글자 미만은 문단 안 앞 단위 물려받기, 60% 미만·동률은 문서 언어). 같은 체계(영·불)는 가르지 않음.
- `Unit.lang`(예외일 때만 — 단일 언어 큐 JSON 불변), 기호 표도 그 언어로. speaker 는 단위마다 lang/voice — 표 안내가 이미 하는 일이라 새 경로 아님. 전환 언어 음성 오류는 NO_VOICE 대신 문서 언어로 다시 + 세션 동안 끔.
- 번역: 대상 언어와 같은 단위는 번역 안 함(호출 감소), 그 밖 다른 언어 단위는 항목 `src` 로. 캐시 키 불변. `SAME_LANG` 은 그대로(완화는 선택지).
- 설정 `tts.scriptSwitch` 기본 켬. 테스트 T-L1–T-L7. **실물 견본 필요** — 한국 PDF 한글 추출(ToUnicode) 확인이 먼저.

## O3 — 8k 에 합침
- 목록 = 언어 → 억양(지역, `voice.lang` 에서) 묶음 → 목소리 이름 그대로. 억양 머리 줄 = "억양만" 선택지(`tts.accent.{lang}` 새 키 4개, voice 없이 lang 태그). 해석 함수 `resolveSpeech` 하나를 원문·번역문·표 안내·퀴즈·O2 가 함께 씀.
- 성별은 API 에 속성이 없어 표시하지 않고 "휴대폰 설정 > 텍스트 음성 변환" 안내 한 줄. 8k Build 지침 문안 6항목은 spec 19-1-2 3.
- 8k-0 진단 페이지에 [voice 없이 en-US / en-GB] 단추와 [en → ko → en 이어 말하기] 간격 표시 추가.
