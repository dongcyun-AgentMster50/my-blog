## C. N2 지금 동작(코드 근거)

- `settings.js` 49–52: `tts.voice.{en,ar,fr,ko}` 기본 `''`. **쓰는 화면이 없다**(읽기만: controls.js 354·403·413, quiz.js 878, ui/settings.js 1038) → 선호 URI 는 늘 빈 값.
- `tts/voices.js` `pickVoice`: 그 언어 음성 중 선호 URI → `localService===true` → 이름 'Google' → 첫 번째. `voice.default` 는 안 본다.
- 고르면 `speaker.js` 373·560 에서 `utt.voice` 지정 → 휴대폰 설정 목소리를 덮어쓴다. 목록에 없으면 `utt.lang`(en-US·fr-FR·ko-KR / 번역문 ar-SA)만 → 엔진이 휴대폰 설정으로 읽는다(Galaxy 진단 2026-10-10 에서 소리 남).
- API 한계: Android TTS 설정을 읽을 수 없다. `voice` 를 비우고 `lang` 만 주는 것이 유일한 "설정 따름".
- 최소 변경(8k): 선호 키가 비면 `voice` 미지정·`lang` 만 + 설정에 언어별 [목소리](휴대폰 설정 따름 / 목록 음성 / 들어 보기). 지역 태그(`ar` vs `ar-SA`)는 Realme A/B 로 정함. 진단 페이지 `dev/voices.html` 에 세 단추 추가(8k-0, 앱 무변).
