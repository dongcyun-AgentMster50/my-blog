## 규칙
- 초안 글은 **그대로** 옮긴다(번호·참조·승인 표시만 고침). 기존 spec 글은 초안이 "한 줄 붙임"이라고 한 곳 외에는 고치지 않는다.

- 같은 작업 트리에서 다른 에이전트(8e Review·8i-4-0 측정 Build)가 돈다 — spec.md 외에는 건드리지 마라. spec.md 를 고치는 다른 에이전트는 지금 없다.
- 명령은 한 호출에 한 가지 일만. 편집은 Edit 도구 또는 Node 스크립트(스크래치패드 `merge/`). 막히면 변형을 찾지 말고 멈춰 보고. 금지: 커밋, `git checkout/restore/stash`, `rm -rf`, npm 설치, `.nojekyll` 삭제.
