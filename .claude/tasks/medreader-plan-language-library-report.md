## 2. 8l 갱신 요지 (spec 19-1-3 3)

- 같은 12쪽 표본에 `garbleCount(str)` 하나: bad = FFFD + PUA + 제어(U+0000–001F·007F–009F, 공백류 제외). `scanVerdict` 에 갈래 하나 — 글자 0 판정이 먼저, 그다음 표본 합 500자 이상이고 bad/chars ≥ 5%(`GARBLE_NUM 1 / GARBLE_DEN 20`) → `'garbled'`. 8l 이 Build 전이라 `SCAN.VERSION` 1 그대로, `documents.scan` 에 `chars`·`bad` 진단 필드.
- 문턱 근거(조사 원값 재계산): 스피쿠스 19.1%(1,143/5,982)–26.0%(2,063/7,942), 정상 최대 0.075%(13/17,309). **띄어진 글자 비율은 쓰지 않는다** — 스피쿠스 1.5–3.8 / 정상 최대 2.34(천 자당)로 겹친다. FFFD·PUA 는 이 폴더에선 0 이지만 일반적인 ToUnicode 누락 꼴이라 합에 넣었다.
- 안내: 카드 배지 `library.card.garbled`, 리더 띠 `reader.scan.garbled`(17-5-1 띠·`noticed` 그대로), 검색 위 한 줄 `reader.scan.garbledSearch` — 네 언어 문안 spec 에(ar·fr 검토 표시). ▶ 는 막지 않음(L-D10 권장). **`--force-ocr` 는 가이드에만.**
- 수용 기준 더하기: 실물 수치 픽스처·경계·변이 2개, Build 첫 단계에서 세 의학 책의 bad 비율이 5% 의 1/10 미만인지 잰다(넘으면 멈춤).

## 3. 8m 갱신 요지 (spec 19-1-3 4)

- O-D6 충족 → 조건부에서 일정으로(8l 다음). 설계(19-1-2 2)는 그대로. 걱정했던 ToUnicode 깨짐은 해커스가 아니라 스피쿠스(Distiller 10) — 8l 이 받는다.
- 견본 4개(전체 경로 spec 에): D.M. B2 정답 및 해설 7쪽(1단, L-D7) · Part7 R.T. B2 해설 14쪽(2단) · bulls eye B2 해설 8쪽(2단) · 천2 Day8 Actual Test 1 사진 12쪽(en+ko — 반대 방향).
- 기대 동작: 앞 셋은 문서 ko → 운영자 대상 ko 라 `SAME_LANG`(번역 꺼짐) + 영어 문장은 en 목소리. 넷째는 문서 en, 한국어 단위 ko 목소리·번역 안 함.
- **Build 첫 단계에서 잴 것 M1–M7**: 한글 추출 bad 0 · guessLang · 단위 분포(**섞임 > 10% `[가정]` 이면 멈춤**) · 보기 `(A) 낱말` 단위 · 2단 읽기 순서(사람 3쪽) · 빈칸 수 · 실기기 전환 간격. 픽스처는 숫자만.

## 5. PC 일괄 OCR 절차 요지 (spec 19-1-3 11)

- 준비: `tesseract --list-langs` 에 `kor` 없으면 `kor.traineddata` 설치(운영자 직접). `ocr-targets.tsv` 를 운영자 PC 로 복사(스크래치패드는 임시), 고른 순번을 `pick.txt` 에.
- 명령(공통 `--rotate-pages --output-type pdf`): 영어만 `-l eng --skip-text --deskew --oversample 300` · 영+한 `-l eng+kor` 같은 옵션 · **깨짐 `-l eng+kor --force-ocr`**(deskew·oversample 없이; `--skip-text` 면 글자가 "있는" 쪽이라 아무것도 안 바뀐다).
- Tagged: OCRmyPDF 는 Tagged PDF 를 거절하는데 pdf.js 진단은 Advanced Grammar 를 Tagged 아님으로 봤다 → 미리 가를 수 없으니 늘 `--skip-text`(깨짐은 `--force-ocr`).
- 결과 크기: Advanced Grammar 56.4 → 182.8MB(×3.24). 우선 A 782MB → 약 2.5GB, Basic Grammar 208MB → 약 670MB `[추정]`.
- 폰용 가벼운 판: `--skip-text` 만(`--oversample`·`--deskew` 없이) — 원본 그림 보존이라 크기 ≈ 원본 + 글자 층 `[가정]`, 150 dpi 인식이라 오인식↑ 가능. Advanced Grammar 한 권으로 `measure-scan-o1.mjs` 비교 후 정한다. PowerShell 일괄 루프(`$light` 스위치·이미 한 책 건너뛰기) spec 에.
- 시간 `[추정]`: 우선 A 약 2시간 · B 스캔 22분 · HP 11분 · 스피쿠스 13분. 확인은 `measure-scan-o1.mjs`, 8l 배포 뒤엔 배지가 없으면 됨. 새 문서로 들어온다.
- zip·hwp·doc·txt: 풀거나 PDF 로 저장해 가져오기(L-D2·L-D3).
